- **MAJOR-1:** `WifiRoute` (Wi-Fi `Network`'s bound `SocketFactory` + `Dns`) carried by every probe and `/healthz` check. Pure `ScanGate.access`: Wi-Fi and not VPN by `Transports`, one throwaway `bindSocket` first; no network or any bind failure → `Unavailable` (no NSD, probe or check). `AndroidWifiWatch : WifiRoutes` binds via `Network.fromNetworkHandle`. `DirectSocketFactory(bind)` closes the socket and throws if the bind fails. `HttpLinkDialer.healthy(pc, endpoint, route)`: the pinned client's `newBuilder()` with the route's sockets/dns and its own zero-idle pool (same trust manager, pin, no token). Manual search → `FindState.CantScan` ("Can't scan this Wi-Fi", EN+ID appended); auto-find skips. Route bound again when the scan starts.
- **MINOR-1:** announced hosts must be `SubnetScan.onLink` the route's Wi-Fi, else dropped before any connection.
- **MINOR-2:** `addFound`/`withFound` store path removed. Found = one-shot link candidate (`EndpointChoice.withFound` puts it first even if not stored). Online on Tailscale: `LinkManager` opens a trial relay beside it (events held until it takes over) and moves only on `gateway.ready`. A failed trial leaves the relay alone. If the trial got the Tailscale relay superseded (4409) and then fails → new round, not a stand-down. Stored by `refreshAddresses` (found first) only after a relay connected through it.
- **MINOR-3:** `ResolveSlot` (pure): pre-34 slot freed on answer, on the 3 s wait timing out, or by a 3 s timer after a cancelled caller. A silent resolve costs a window ≤ 3 s.
- **MINOR-4:** `AppLock(schedule)` arms a cap timer at `authStarted` (main Handler); expiry judges a held-back return while in front; also checked on start/stop. Checks now have ids (`authStarted(): Long`, `authEnded(id, passed)`) instead of the `abandoned` counter. `AuthBroker` proceeds past a stuck `busy` once `AppLock.checkRunning()` expires it; a late end never clears a newer check's busy.
