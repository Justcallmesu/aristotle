# T20 build report: Aristotle app icon (concept B simplified)

- **Mark:** this is concept B (`thinker.svg`) redrawn with the silhouette first. Curls and beard are one ink mass around a parchment face. The profile is a 4.8-unit line, which is 3.2 dp at 48 dp. A larger fist with knuckles sits under the chin with a clear gap. The forearm runs down, and the hunched draped shoulder has one fold. The fold is an even-odd hole, so the monochrome layer needs no mask. No text and no hatching. The furthest point is 32.4 of the 33 dp safe-zone radius; the script checks this.
- **Masters:** `docs/design/icon/aristotle-b2.svg` (108×108, ink on parchment) and `docs/design/icon/aristotle-b2-monochrome.svg`. Everything comes from `docs/design/icon/build_icon.py`: edit the geometry there and re-run it.
- **Android:** `drawable/ic_launcher_foreground.xml` (ink), `ic_launcher_background.xml` (parchment), `ic_launcher_monochrome.xml` (themed icon) and `ic_stat_aristotle.xml`. The status-bar icon is white with alpha, a group-scaled copy of the same mark without the fold. `mipmap-anydpi/ic_launcher.xml` and the new `ic_launcher_round.xml` point to the three layers. In the manifest, `roundIcon` now points to `@mipmap/ic_launcher_round`.
- **Legacy PNG mipmaps:** not needed and none added. minSdk is 29, and adaptive icons work from API 26.
- **Notifier.kt:** unchanged, because it already uses `R.drawable.ic_stat_aristotle`, which T20 redrew.
- **QuoteLoadingScreen.kt:** now shows `ic_launcher_monochrome`, tinted `colorScheme.onSurface`, in the same 88 dp tile. The plain ink foreground would have disappeared on the dark tile (`#2D2721`). Nothing else changed.
- **Preview sheet:** `docs/design/icon/preview.html`. It shows 48, 64 and 108 dp, in circle, squircle and rounded-square masks. Each appears on a light wallpaper, on a dark wallpaper, and as a themed icon in light and dark. The sheet also has the canvas with its guides and the status-bar icon.
- **PNGs:** rendered at 3× with `rsvg-convert`: `docs/design/icon/png/{canvas,light,dark,themed-light,themed-dark,status}.png`.
- **Gate:** `GATE_ONLY=android gates.sh runs/T20` exits 1, and only because of T18b's file. `CronViewModelTest > createSendsOneAddAndShowsHermesOwnRefusal` fails (566 tests, 1 failed); that test is T18b's in-progress cron work. Gradle stopped before `assembleDebug`, so I ran `./gradlew lintDebug assembleDebug` separately. It passed: lint 0 errors, and the APK built.
- **Leftover for the PM:** `res/values/ic_launcher_background.xml` (old `#2E3A59` colour) is now unused and lint warns about it (UnusedResources). It is outside T20's files: delete it.
- **Open:** the user approves on the Poco, since 48 dp legibility on the device is the real test. The themed-icon tones in the preview are representative; the real ones come from HyperOS or the wallpaper. Not installed, not committed.
