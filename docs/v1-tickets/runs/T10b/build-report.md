# T10b build report — SessionWatcher fix round
Gate: `GATE_ONLY=android bash docs/v1-tickets/gates.sh docs/v1-tickets/runs/T10b` → PASS (exit 0; lint + 163 unit tests + assemble).

1. **MAJOR replay_gap**: `SessionWatcher` handles `session.replay_gap` for a watched id: removes it from `resumed`, resumes it again on the same socket (launched, so frames keep flowing; `resuming` guard against a duplicate in-flight resume). Unwatched ids ignored. Test: `aReplayGapResumesTheWatchedSessionAgainOnTheSameSocket` (second resume, no extra `session.list`, prompt re-read from the new snapshot).
2. **No repeat alerts**: `AlertRouter` keeps posted prompt ids in memory; a re-post of a known open prompt is `repeat` → `setSilent` + `setOnlyAlertOnce`. Swipe is tracked via `deleteIntent` → new non-exported `AlertDismissReceiver` → `AppContainer.onAlertDismissed` → `router.onDismissed`; a dismissed prompt is never re-posted. Opening the session also counts as dismissed. After each resume the watcher emits `SessionAlert.PromptsOpen(sid, ids)`; the router cancels `needs:` when the shown prompt isn't open. Tests in `AlertRouterTest` (repeat, dismissed, older-prompt dismiss ignored, snapshot cancel) and `SessionWatcherTest` (PromptsOpen emitted).
3. **Approval wording**: `NeedsYou.command` / `AlertBody.Approval(command)`; set only when the prompt has a non-blank `command` that is not a `<…>` placeholder (file-write). Command text is still never shown. New string `notify_needs_approval_generic` ("Wants your approval…" / "Meminta persetujuan Anda…", EN/ID); "Wants to run a command" only for command approvals.
4. **docs/protocol.md §2 note**: "stays resumed until a replay_gap or the socket ends"; added the `cancel_persisted_close` side effect (TUI/CLI mid-turn close can be cancelled by the phone's auto-resume; Desktop unaffected; orphan close re-armed on drop).

Files: `data/{SessionWatcher,AlertRouter}.kt`, `background/{Notifier,AlertDismissReceiver(new)}.kt`, `AppContainer.kt`, `AndroidManifest.xml`, `res/values{,-in}/strings.xml`, tests `AlertRouterTest`, `SessionWatcherTest`, `docs/protocol.md`.
Caveats: not run on a phone (deleteIntent/silent repost untested on-device). Edge: with two open prompts in one session, dismissing one then reconnecting can re-post the other silently. Existing watcher tests changed to expect `PromptsOpen` and `command=true`.
