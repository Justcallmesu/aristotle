# T17 build report — subagents: live rows, open one, stop one

**How the Desktop does it** (Hermes @717447e, read-only). Children report as `subagent.*` events **on the parent's stream**; rows sit under the `delegate_task` tool call (goals from args, settled by its result, live state wins). Opening: the card opens `child_session_id` in a watch window (a `session.resume`), but on the canonical `/api/ws` owner that is a read-only history mount with no live events (the child mirror is sidecar-only). The Desktop's live view of a child on the canonical path is the composer detail: the roster's stream plus `subagent.tail` every 2 s. Stop: per child `subagent.interrupt`, no confirmation. **No "stop all"** (composer Stop ends the parent turn, not background children). A child ending does not notify; `turnDone` stays on `message.complete`.
