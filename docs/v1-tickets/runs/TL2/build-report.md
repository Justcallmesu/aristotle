- **AppLog** (`data/AppLog.kt`): the one log door (`AppLog.d/i/w/e(event, error?)`, error = class name only) → `LogPipeline` (bounded queue, one daemon writer thread, redacts, debug-only logcat) → `RingLog` (`data/RingLog.kt`, `noBackupFilesDir/debug-log/`, 2 × 256 KB rotated). Redaction `data/LogRedactor.kt`: bearer, token/token_sealed/authorization/pin/pairing_code values, rest of line after password/secret/value and content keys (text/message/prompt/reasoning/output/body), URL query+fragment, opaque ≥32-char base64url, pairing codes, fingerprints keep 8 hex, "JSON input:" cut. Routed: `AppContainer` (link handler, Wi-Fi/LAN `log` lambdas, new link-state line), `BackgroundController`, `LinkService`. `ui/theme/Theme.kt`'s `Log.w` (constant text) left alone (not my files), allow-listed in the guard test.
- **Crash** (`data/CrashReports.kt`): `Diagnostics` started first in `AristotleApplication.onCreate`; handler writes `crash.txt` (build, Android, device, thread, class + redacted ≤300-char message, ≤80 frames × ≤8 causes, last 200 log lines), then chains to the previous handler. Next launch: offered once (renamed `crash-offered.txt`; a stale offer is deleted).
- **Crash screen** `ui/CrashDialog.kt`, composed in `AristotleApp` after the lock check (never above the lock). Send report → one file in `cache/share/` → share sheet (`background/DebugShare.kt`, FileProvider `<cache-path name="share" path="share/">` added to `res/xml/file_paths.xml`, existing `${applicationId}.files` authority). Dismiss/Back deletes. Nothing uploads.

- Technical readings for PM: "offer once" = a crash not acted on is dropped at the next launch; Send also deletes it; Back = Dismiss.
