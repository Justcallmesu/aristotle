- **Q68 folding:** `ToolFolding.rows` (new pure `ToolFolding.kt`) folds runs of 3+ tool calls into `TranscriptRow.Folded`. Only a message, notice, card or delegate card ends a run. Reasoning between the calls goes into the fold; reasoning before or after the run stays outside, so a streaming "Thinking…" stays visible. The key is `fold-<first call>`, so the card keeps its place and open state as the run grows. `FoldedToolsCard` (ChatItems) is a 48 dp header, "N tool calls · last: **name**", with the last call's icon, a spinner while a call runs (only when live) and "Failed" in red if any call failed. It is collapsed by default and opens to the single cards, 4 dp apart. The subagent page uses the same folding.
- **C1 / Q68 paths:** `ToolSummary.display` (ChatText.kt) is display-only; `ToolText` is unchanged. It turns `/home/<u>`, `/Users/<u>`, `/root` and `$HOME` into `~`. Paths with more than 4 segments become first segment/…/last two (`~/…/scratch/safe.sh`). A summary that is one path longer than 32 chars puts the file name first (`safe.sh · ~/…/scratch`). For shell tools (terminal/shell/bash) it drops leading `VAR=…;` / `&&` assignments. URLs are left alone. I did not add a separate common-prefix strip across cards; the home dir → `~` plus the middle ellipsis cover it.
