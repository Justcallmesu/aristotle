# T19b build report — remote terminal, phone side

- **Library:** Termux `com.github.termux.termux-app:terminal-emulator` + `terminal-view` **v0.118.3** (latest tag), JitPack only (repo added in `settings.gradle.kts`, `includeGroup` = that group only). Licence: termux-app `LICENSE.md` @v0.118.3 says the repo is GPLv3 *except* these two libraries, Apache-2.0 (jackpal Terminal Emulator code); the AARs/POM carry no licence file (POM says "Other"). AAR minSdk 24, no minCompileSdk; builds with AGP 9.4.1 / compileSdk 36. `libtermux.so` excluded from the APK (`packaging.jniLibs.excludes`).
- **Deviation (PM check, brief said STOP if not clean):** Termux's `TerminalView` widget is NOT used. `TerminalView.attachSession` takes the `final TerminalSession`, whose first `updateSize` forks a local shell through JNI (`initializeEmulator` → `JNI.createSubprocess`), and its `onCreateInputConnection` is final with hard-coded `imeOptions = IME_FLAG_NO_FULLSCREEN` (no `NO_PERSONALIZED_LEARNING`). Only reflection hacks fix either. Used instead, all public API: `TerminalEmulator` + `TerminalRenderer` (from terminal-view) + `KeyHandler`, drawn by our `ui/terminal/RemoteTerminalView` (~250 lines: draw, IME, keys, scroll, pinch). No VT parser was written. If the PM rejects this, the options are a reflection shim on `TerminalSession`, a fork of terminal-view, or another emulator.
- **How bytes reach the emulator:** `TerminalSocket` (OkHttp `/v1/terminal`, pinned client of the link's current endpoint from `HttpLinkDialer`, Bearer token, not the relay) → `onMessage(ByteString)` on the reader thread → `OutputQueue.offer` (512 KiB, drop-oldest, counts skipped bytes, never blocks) → conflated wake → main-thread `TerminalTab.drain` (64 KiB steps + `yield`) → `TerminalEmulator.append`. Before each drained batch with drops, the marker `CAN` + "[output skipped: N bytes]" goes in. `TerminalEmulator(output=RemoteOutput, …, client=SilentClient)`: `RemoteOutput` (a `TerminalOutput`) sends user writes (paste, mouse wheel) as binary frames. Writes made inside `append` are answer-backs and pass only `Answerback.allowed` (numeric CSI c/n/R/$y/t, OSC colour `rgb:`). DCS DECRQSS/XTGETTCAP and label reports are dropped. OSC 52 copy/paste and the title are no-ops. `SilentClient` (`TerminalSessionClient`) drops Termux's log text, which quotes sequences.
- **Transport:** `resize` JSON goes first on open (protocol §14), then debounced 150 ms (`ResizeGate`). Input goes in ≤16 KiB frames. Close/HTTP mapping is in `TerminalEnd` (4401 → "This phone was revoked", 4403 → "Terminal turned off on the PC" / no grant + `TerminalAccess.turnedOff()` hides the entry, 1006/1011 pong/network change → "Terminal closed (connection changed)" + Reopen, `exit` code shown on 1000, 4408/4430/1001/shell_start_failed each have their own text). A JSON 403 is told apart from the peer gate's text `forbidden`. Nothing reconnects. Reopen builds a new connection.
- **Screen:** terminal icon in the sessions top bar, shown only while `TerminalAccess.target` != null (`GET /v1/me` read again on every new `LinkState.Online` generation, both flags). Top bar has address + via/state + Close; the overflow has Copy screen / Paste / New terminal. Up to 2 tabs. Extra keys: Esc Tab Ctrl/Alt (one-shot sticky) ↑↓←→ Home End PgUp PgDn | / - ~. Atkinson Hyperlegible Mono via the Compose font resolver, pinch zoom 11–24 sp (default 13), palette A fg/bg/cursor + a light ANSI set (≥ 5.2:1 computed). EN + ID strings.
- **Safety flags (code-verified, not on device):** input `TYPE_CLASS_TEXT|VISIBLE_PASSWORD|NO_SUGGESTIONS`, `IME_FLAG_NO_PERSONALIZED_LEARNING|NO_FULLSCREEN|NO_EXTRACT_UI`. The view is excluded from autofill and (API 30+) content capture. FLAG_SECURE is on whenever the screen shows (no opt-out in this ticket). Clipboard is touched only by the Copy screen / Paste menu items; copies get `EXTRA_IS_SENSITIVE` on API 33+. Nothing in the terminal path logs.
- **Lifecycle:** a `RouteStores` per terminal route. Leaving clears the ViewModel (`onCleared` closes every socket with 1000). `LifecycleStartEffect` `onStopOrDispose` closes all tabs when the app goes to the background (not on rotation). A network change cancels every tab. T10's service holds no terminal.

- **Tests (46, all pass):** `TerminalFramesTest` covers resize, exit/closing, paste chunking and the close/HTTP mapping. `OutputQueueTest` covers drop-oldest, the skipped count and a concurrent producer that never exceeds the cap. `TerminalConnectionTest` covers first resize, debounce, chunks, first end wins, and no reconnect or reopen after any end. `TerminalAccessTest` covers the visibility rule, `/v1/me` per connect and hide after 4403. `AnswerbackAndKeysTest` covers answer-backs and keys. `TerminalSocketTest` runs a local TLS WebSocket: binary both ways, Bearer, `/v1/terminal`, 403 JSON, 4403, and `/v1/me` parsing. `TerminalTabTest` drives the real Termux emulator in the JVM: UTF-8 split across frames, output before the first layout, numeric-only answer-backs, OSC 52 ignored, bracketed paste with ESC stripped, the skip marker. Mutation check: turning off the answer-back filter fails `TerminalTabTest`.
- **Gate:** `GATE_ONLY=android bash docs/v1-tickets/gates.sh docs/v1-tickets/runs/T19b` → exit 0 (`SKIP server`, `PASS android`: lint, unit tests, assembleDebug). `unzip -l app-debug.apk` lists no `libtermux.so`. Lint still warns `Aligned16KB` for the dependency's `libtermux.so` (it checks the AAR, not the packaged APK).
- **Mismatches to report:** the protocol has no PC name (`/v1/me` `name` is the phone's own), so the top bar shows the PC's address. Protocol §14 says pastes split at 64 KiB; the brief says 16 KiB, which is used and is compatible.

Not checked on hardware: the IME behaviour (Gboard/HyperOS keyboard with visible-password: no suggestions, no learning, Enter → CR), that FLAG_SECURE blanks recents, rendering and font download, pinch and scroll feel, keyboard-resize debounce, how a 1006 looks after a real Wi-Fi switch, and throughput under `yes`.
