- **APK delta:** the six font entries add 357,780 B raw / **181,908 B compressed**. Per-entry diff against the previous debug APK: those six are the only new entries; the rest is dex (+12 KB, code) and the vector icons (a few hundred B). The APK file sizes can't be compared because the old build's zip had different padding.
- **Type scale:** `Type.kt` `TextStyle.scaled(scale)` clamps at `MinTextSize` 11 sp, and line height and tracking scale by the same factor.
