# TS2 build report — phone: Stocks slice 1

1. **Built:** Home's Q92 title words "Chats  Stocks" sit where the wordmark was. They act as a tab row (Role.Tab with a selected state), and the choice is kept in `AppSettings.homeMode`. The avatar is unchanged and Chats looks the same as before. The Stocks view (`ui/stocks/`) has: the market line; the watchlist (two-line rows, `quote.spark` sparkline); the holdings card; a news strip; an add-to-watchlist search sheet; Move up/Move down/Remove on long press; pull to refresh; and offline, stale, closed and empty states. Further pages: Holdings (list, add/edit sheet with a P/L preview, delete with confirm), News (All/Watchlist/Holdings, day sections, chips, link via `ACTION_VIEW`), placeholder `stock/{code}` (`PairedPage.StockDetail`), and Settings › Stocks (fees, "Broker app: Ajaib" with Open only when installed, `<queries>`).
2. **Data:** `data/stocks/` holds the §20 client, which goes over the pinned client via `HttpLinkDialer.send`. It also has `QuoteRefresh` (reads every 60 s only while visible, online and the market is open, plus one read at `next_open`), `StockFormat`, `StockChanges`, `HoldingInput` and `HoldingMath`, which mirror the server's P/L rounding. `ServerClient.execute` was moved into a shared `OkHttpClient.await`.
3. **Colours (Q91):** `StockColors` holds the stocks-notes table and is provided by `AristotleTheme`. It is not part of the M3 slots. Every change also shows an arrow and a sign. I added one Q91 line to `docs/design.md` and one Phone line to the CHANGELOG.
4. **Tests:** 59 new tests covering formatting, P/L mapping, the refresh rule and loop (fake clock), reorder, validation and the preview checked against the server's numbers, switch persistence, transport (MockWebServer TLS), the ViewModel (6), and parsing of 17 fixtures. The fixtures are real handler output, made by running the server test harness in a scratch copy; `server/` was not touched.
5. **Gate:** `GATE_ONLY=android bash docs/v1-tickets/gates.sh docs/v2-stocks/runs/TS2` exits 0 (PASS android: lint, 1162 unit tests with 0 failures, assembleDebug). Not run on a phone (no adb), so the layout is unchecked by eye.
6. **ASK — the board and §20 disagree:** the board blocks Save with an "off-tick" average price error ("Try 4.370 or 4.380"). §20 accepts any average to 0.01 IDR, and an average of several buys is often off-tick. I followed §20 and added no tick check. Should there be a non-blocking hint instead?
7. **Contract notes:** `spark` comes as `null` (not `[]`) for a quote with no bars; it is read as empty. The fake source sends `market_time:null`, so "as of" falls back to `at`. Stocks only work while the link is `Online`, because HermesDown carries no address even though the server could still answer. The offline line can't name the PC (the protocol has no PC name).
8. **Design deviations:** Settings has a 4th block, [Stocks] (design-notes §5.4 has three); `SettingsBlocksTest` is updated to match. The Remove text button is red because it is destructive, as on the board.
