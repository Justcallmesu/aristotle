# TS3 build report — phone: stock detail page + chart

1. **Built:** `StockDetailScreen` replaces the placeholder at `stock/{code}`, following the board's three detail screens. It has: a top bar (code in Mono 18, name, ⋮ for Add/Edit holding and Add to/Remove from watchlist); the price at 32/40 with a Q91 change and an as-of line; the 44 dp readout; the chart; range chips 1D 5D 1M 6M 1Y (the board has no 5Y) and a candles/line toggle; a "Today" card (open, prev close, high, low, volume in lots, 52-week range, tick, ARA/ARB with "n/a"); the holding card or "You don't hold X · Add holding"; up to 5 "News about X" rows (`?code=`) with "All"; and "Open in Ajaib" (launch intent, hidden when not installed, checked on resume). The holding sheet, its fees and the watchlist calls reuse the shared `StocksViewModel`, which has a new `detailVisible`.
2. **Chart (P3):** the pure module `data/stocks/StockChart.kt` covers: `IdxTick`; `PriceScale` (8 % / one-tick padding, nice steps rounded to the IDX tick); `BarAxis`, which places bars by slot (1D on the full S1+S2 day with the break collapsed and marked, Friday hours included; 5D one bar per index with day breaks); allocation-free `barAt` snapping; WIB labels per range; and `ChartReadout`. `PriceChart` draws ink-only hollow-up/filled-down candles (or a `primary` line), volume, the grid, the dashed last line and its tag, and the dotted 1D prev close. Everything is built in `drawWithCache`. The crosshair is a separate draw layer (long-press drag, `SegmentFrequentTick` per new bar, cleared on lift) that measures each bar's tag only once. TalkBack reads one description of the range, last, change, high and low.
3. **Data:** `StockDetailViewModel` (one per code, its own `RouteStores`, cleared when you leave the page) keeps bars per range (`ChartCache`: other ranges stay cached; 1D goes stale after 60 s). A `QuoteRefresher` with the TS2 rules re-reads the quote and 1D every 60 s while the page is visible, reachable and the market is open; the day's open comes from 1D. States covered: `stale:true` line, 503 `retry_after_s` error with Retry now plus an automatic re-read, empty / loading / offline.
4. **Server range map (not the board's):** §20/`ChartRanges` uses 1D=5m, 5D=15m, 1M=1h, 6M/1Y=1d. The board says 30m/1d/1wk. I followed the server, and the readout hint ("one 5-minute bar / hour / day") reads the interval from the answer.
5. **Tests:** 35 new tests: scaling (flat, one bar, penny stocks), price ticks, gap collapsing (from the fixture: no lunch bars), snapping, readout math, labels and spans, range→request, the refresh/cache rule and a VM loop with a fake clock, 503/stale, and holding math against §20's example. `chart_5d.json` / `chart_5y.json` are the server's own `parseChart` output over its testdata, made in a scratch copy; `server/` was not touched.
6. **Gate:** `GATE_ONLY=android bash docs/v1-tickets/gates.sh docs/v2-stocks/runs/TS3` → see `gate-summary.txt` (final run after this report). One earlier gate run also failed `RepairTest.successReplaces…` (pairing, not touched here). It passes alone, so it looks like an existing timing flake.
7. **Not checked on a phone** (no adb): layout at 1.3× font scale (time labels may overflow the chart's 250 dp by a few px), how the haptic feels, and that drawing stays smooth on 1Y.
8. **Deviations:** "All" opens the News page, and Back from there goes Home (the page model has one `back`). `stocks_detail_soon` is now unused but kept (strings are append-only).
