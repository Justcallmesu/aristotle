## Findings (all MINOR / nit — none triggers a round)
- **MINOR-1: a settings change can be overwritten by an older-settings result.** A scan reads its settings at the start (screener.go:501) and saves its result at the end (:626-628). A PUT that lands in between re-ranks (:836), and then the scan's old-settings result replaces it. Reproduced in 1 of 3 stress runs: breakout was shown while the stored settings had it off. Intraday heals at the next slot. EOD (:444) heals only at the next `bars.daily` or PUT. Fix: a settings generation number; re-rank after saving when it changed.
- **MINOR-2: PUT accepts `null` for scalar fields.** `sameKeys` only checks that keys exist (screener_settings.go:93-103). `"min_value_bn":null` becomes 0, which turns the liquidity floor off; `"on":null` becomes false. Both answer 200, while §20.3 says "every field present". Fix: refuse a `nil` value.
- **MINOR-3: two hits-log issues for slice 3, to decide before TBA1.**
  - Hits added by a re-rank (:704) or by a GET-triggered EOD screen (:813) carry `at` = now and the same `mode` as a live scan. TBA1 can tell them apart only by `data_as_of`/`date`.
  - Bullish setups on an illiquid watchlist code, or on a held code outside the universe and watchlist, never reach `hits` (screener_setups.go:350-357, screener.go:274). Q87/Q107 expect alerts for watchlist (+ holdings). This matches TS4, so it is a PM call, not a build defect.
- **MINOR-4: one try per code per day for the open.** opensTried is set on any non-block error, and also when the `5d` chart has no bar for today yet at about 09:05 (screener.go:651). That code then has no gap for the rest of the day, until a restart. Separately, opens are cached in the 200-entry chart LRU (provider.go:284): up to 80-180 `|5d:1d` entries that push out the phone's charts.
- **MINOR-5: the mismatch check runs before the usable check (screener_setups.go:167-171).** A quote whose market time is not today (suspended, no trade yet) has a previousClose one session older, so the whole code is dropped, including its stored `ma_cross` and its flags.
- **Nits:**
  - The strict decode of the stored file (screener.go:143) means a later additive field with no version bump would push a rolled-back binary to defaults. The file stays untouched, so nothing is lost.
  - With 51-59 bars and `lookback` 60, the intraday breakout silently never fires (screener_setups.go:199).
  - `charts++` also counts a blocked `ChartFresh` that never called Yahoo (screener.go:595).
VERDICT: PASS-WITH-FINDINGS
