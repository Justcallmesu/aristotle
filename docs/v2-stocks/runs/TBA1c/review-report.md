## Findings
- **MINOR-1: `akhir`/`awal` (and, more weakly, `sejak`/`since`) can introduce a price, like the `pada`/`hingga` words TBA1c2 removed (brief.go:845-846).** These pass: `target awal 2050`, `harga akhir 2050`, `support awal 2050`, `resistance akhir 2050`, `naik sejak 2050`, `up since 2050`. Only a bare 4-digit number from 1990 to 2099 gets through (`2.050` is still refused). The model must also break the prompt rule first. Fix: drop `akhir|awal` and let the prompt say `akhir tahun 2026` (that already passes via `tahun`). Or keep them only when the word before them is not a price noun (`harga|target|support|resistance|level|area|zona|entry|stop|tp|sl`). Recommended before commit, to stay consistent with TBA1c2.
- **MINOR-2 (pre-existing, not introduced): split digit groups and non-ASCII digits get past `numberRe` (`\d` is ASCII; brief.go:72).** These pass: `Rp 2 050`, `Rp 10 000`, `2`NBSP`050`, `2`U+2009`050`, `Rp 2'050`, `support ２０５０` (fullwidth), `٢٠٥٠` (Arabic-Indic). They are unlikely from Opus. Fix: map `unicode.IsDigit` runes to ASCII. Then join a space/NBSP/U+2009/U+202F/`'` followed by exactly 3 digits into the number, or refuse a 3-digit token with a leading 0 and any number after `Rp|IDR`.
- **MINOR-3 (repair cost, accepted trade-off): ordinary year text is still refused.** Examples: `pada 2026`, `di 2026`, `tahun buku 2025`, `laba/kinerja 2025`, `2025-2026`, `tahun 2025-2026` (second year), `2025/2026`, `pertengahan/medio 2026`, `(2026)`, `3Q2025`, `9M2025`, `Q3-2026`, `tahun`NBSP`2026`, `06-11-2026`, `Agt/Nop 2026`. The prompt names the allowed forms, so most mornings should pass. Each slip costs one extra Opus turn, and `invalid_brief` happens only if the repair fails too. Optional: add the safe words `pertengahan|medio|buku`, allow a year range after an accepted year, and accept `Q|H|M` glued to a year.
- **NIT-1 (doc/prompt drift):** the prompt (brief.go:633-635) lists fewer forms than the code: no `thn`, `quarter`, `<year> tahun`, `EMA 50`. That direction is safe. §20.4 (protocol.md:1522-1526) differs from the code in four places:
  - It says `semester I-II`; the code accepts I-IV, plus `quarter`.
  - It says `LQ|IDX|Q|H` pass "after one space"; in the code only `MA|EMA|SMA|RSI` + 2-3 digits pass after spaces.
  - The PM's hand edit leaves `(EN/ID)` dangling after the new parenthetical.
  - It does not say that an empty POST body is accepted.

  `TestBriefPromptStatesYearRule` pins only substrings. Building the prompt's word list from `yearBeforeWords` would keep the two in sync.
- **NIT-2 (design note):** "same as `persist=false`" turns one transient write failure into no saves at all for the rest of the process (items, `fired`, `hits_cursor`). On restart the unsaved increment is lost: each restart on a still-failing disk can leak one run. A `runsOff` flag that keeps trying to save would fix the counter on the next good write. This conforms to the brief; noting it only.
- **NIT-3:** no test pins the `deleteSession` log attrs (`code`/`date`, `err`): a mutation that drops them survives.
VERDICT: PASS-WITH-FINDINGS (no BLOCKER or MAJOR; MINOR-1 is a small priceLike hole of the same class TBA1c2 closed, best fixed before commit; NIT-2/3/4 closed as specified)
