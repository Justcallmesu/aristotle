Aristotle icon (T20, concept B simplified)

The hand-on-chin bust from the engraving, silhouette first: curls and beard as one mass, the profile as a 3.2 dp line at 48 dp, the fist under the chin with a clear gap, the hunched draped shoulder with one fold. Ink #2B2119 on parchment #F3EAD8. No text, no hatching. Furthest point from the centre: 32.4 dp of the 33 dp safe-zone radius.

Sizes are CSS px = dp at 1x. On the Poco (about 2.75x) the 48 dp tile is about 132 device pixels. Approve on the phone.
