Aristotle v2 — redesign board

Chosen (Q75): Home C, Soft corners, effort slider, the “N steps” line; TD2b adds the profile avatar and sheet (section 1b). Spec Q74. Palette A is unchanged; what changes is the component shape language (corners, fields, grouped rows, a floating composer, quiet step lines) and the home layout. Every screen is drawn at 393 × 873 dp, light and dark, from Material 3 Compose parts only. Notes and the Compose mapping: docs/design/v2/design-notes.md.

Content is real: session titles and message counts from the pm profile, tool names and output from this project's chats, the model catalog Hermes serves (Anthropic 13, OpenRouter 60, GitHub Copilot 44). Day groups are shifted by one day so Today / Yesterday / Earlier all show. State demos, not data: the "Needs a paid plan" lock on one Copilot model, gpt-4o-class models having no reasoning (pick one to see the effort footer disappear), the sample fingerprint and the two invented addresses besides 100.74.61.96. Taps on rows, chips, ⋮ and buttons follow the primary path; on the board they jump to the target screen, in Clickable path they navigate one phone.

Clickable path

  1. Home (C, chosen): tap a live card or row, the profile avatar (top right), ⋮ or New chat.
  2. Profile sheet: pick a profile; tap the dimmed home to close.
  3. Chat: tap the model chip, the "Waiting for your approval" chip, the steps line, or the message field.
  4. Model sheet: search, open/close providers, drag the effort slider, pick a model. Tap the dimmed chat to close.
  5. Approval: Deny, Allow once, or Always allow (second step).
  6. ⋮ › Settings › Connection & PCs, then back.

Theme and Corners tweaks apply here too. Theme "Light + dark" shows light.
