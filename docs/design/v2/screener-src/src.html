Aristotle — Screener board (TD5, slice 2)

The screener scans ~80 liquid IDX stocks for five built-in setups (Q85, Q86) and lists the candidates. Same v2 stocks language as stocks.html: palette A, Soft corners, grouped rows, Literata titles, Atkinson Hyperlegible Next / Mono, green / red text for change (the TD4 recommendation), M3 Compose parts only. 393 × 873 dp, light and dark. Notes and the Compose mapping: docs/design/v2/screener-notes.md.

Surfaces. Stocks home section, Screener page and every state are Monitor (read a list, decide what to open); Settings is Configure. Tapping a row opens the stock page already drawn in stocks.html; there is no Analyze on a row (TA2: a stray tap must not start an Opus run).

Samples, not quotes. Codes are real IDX tickers, but prices, volumes, scores, times and which stock fires which setup are made up for the board. They follow the real rules: ticks 1 / 2 / 5 / 10 / 25, ARA 25 % in the 200–5.000 band, Yahoo's 10 min delay, setup formulas and score weights from TS4 §3, the GET /v1/stocks/screener fields. Samples are dated Thu 5 Nov 2026. Bearish chips appear only on watchlist / holding rows (Q106).

Picks for the user (recommended one first, all are Tweaks): 1 candidate rows two-line 64 dp · one-line 52 dp · 2 setup labels tonal fill · outline · 3 home section under the watchlist · first · 4 universe: Edit list button · read-only (TS4's reading; the brief asks for the button).

Clickable path

  1. Stocks home: pick a Scenario in Tweaks, scroll to Screener, tap See all.
  2. Screener page: Today / Last close, filter chips, ⋮ (Scan now, cooling down), gear.
  3. Settings: switches and − / + steppers work, Save enables on a change, Defaults resets. Edit list opens the sheet.
  4. A candidate row opens the stock page in stocks.html (new tab).

All Tweaks apply here. Theme "Light + dark" shows light.
