## IPC commands (`app/src/ipc.rs`; all registered in `main.rs`, all in capability file)
| Command | Core/CLI call | UI event |
|---|---|---|
| `snapshot(fresh?)` | core poll -> `Snapshot` + assessment (DTO) | `snapshot` (also from the 5 s poller, window-open only) |
| `start_intent` | pending `StartIntent` (args.rs) | `start-intent` on hand-off by single-instance |
| `service_action(start\|stop\|restart)` | `service.rs`: stamp before stop/restart, deleted on failure (DF6); guard refuses on mismatch / not installed / no CLI | `snapshot` after |
| `pair(name?)` | `pairing::issue_code` -> §22 pair result incl. `qr_payload`; Debug hides code/payload | none (never stored/logged) |
| `devices_revoke(id)` | `devices::revoke` (id that looks like a flag refused) | `snapshot` |
| `terminal_status` / `terminal_grant(id)` / `terminal_ungrant(id)` / `terminal_enable` / `terminal_disable` | `terminal.rs` -> CLI | `snapshot` after writes |
| `logs_start` / `logs_stop` | `logs.rs`: `aristotle-server logs -f` child (own group) | `logs-lines {lines}`, `logs-ended` |

Logs child is killed on `logs_stop`, on starting again, and on `WindowEvent::Destroyed`; the process exits when the window closes (no tray). `tauri-plugin-single-instance` hands args over. Capabilities: only the 11 app commands (+`terminal_status`, `start_intent`) plus `core:event:allow-listen/unlisten`; no shell/fs/http/opener. CSP: `default-src 'none'; script-src 'self'; style-src 'self'; font-src 'self'; img-src 'self' data:; connect-src ipc: http://ipc.localhost; ...`; `withGlobalTauri: false`. Window 960x640, min 720x520.
